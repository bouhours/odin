Comment accéder au relevé de note d'un étudiant ?

  • Cliquez sur le menu "Notes", si ce n'est pas déjà fait.
  • Sélectionnez, à gauche, le groupe de l'étudiant.
  • Cliquez sur l'étudiant concerné.
  • Son relevé de note de l'année courante apparaît.
  • Vous pouvez accéder à ses anciennes notes en utilisant la liste déroulante des années située au-dessus du relevé.

Comment accéder et/ou justifier une absence ?

  • Cliquez sur le menu "Absences".
  • Sélectionnez l'étudiant concerné dans le menu de gauche, ou repérez le dans le résumé de la page centrale.
  • En dessous de la photos de l'étudiant, repérez les boutons associés à l’absence que vous souhaitez justifier.
  • La croix verte permet d'indiquer qu'une absence est justifiée pour raison médicale.
  • Le document blanc permet d'indiquer qu'une absence est justifiée par un document administratif.
  • Le rond vert permet d'indiquer qu'une absence est justifiée par le responsable de la formation.
  • La zone de saisie à côté des boutons permet de donner un commentaire à l'absence tant qu'elle n'est pas justifiée officiellement.

Comment valider la justification d'une excuse à une absence saisie par un étudiant ?

  • Les excuses peuvent être saisies par les étudiants ou par vous-même. Si un étudiant effectue lui-même la saisie, il doit joindre une copie numérique de sa justification que vous devez alors valider.
  • Cliquez sur le menu "Absences".
  • Sélectionnez l'étudiant concerné dans le menu de gauche, ou repérez le dans le résumé de la page centrale.
  • Au dessus de la photo, dans le cadre "Liste des excuses présentées", repérez les excuses avec l'icône
  • A côté de "Validez-vous la justification de l'absence ci-dessus ?", vous pouvez choisir de quel type de validation il s'agit.
  • Vous avez la possibilité de télécharger la justification de l'étudiant en cliquant sur "Cliquez ici pour la voir"
  • Toute absence passée ou à venir est automatiquement justifiée avec les informations que vous avez saisi

Comment saisir une excuse à une absence ?

  • Les excuses peuvent être saisies par les étudiants ou par vous-même. Si un étudiant effectue lui-même la saisie, il doit joindre une copie numérique de sa justification que vous devez alors valider.
  • Cliquez sur le menu "Absences".
  • Sélectionnez l'étudiant concerné dans le menu de gauche, ou repérez le dans le résumé de la page centrale.
  • Au dessus de la photo, dans le cadre "Créer une excuse pour cet étudiant", saisissez toutes les informations.
  • Cliquez sur Enregistrer.
  • Un résumé apparaît dans le cadre "Liste des excuses présentées".
  • Toute absence passée ou à venir est automatiquement justifiée avec les informations que vous avez saisi

Comment imprimer un état d'absence pour un groupe donné ?

  • Cliquez sur le menu "Absences".
  • Sélectionnez le groupe concerné dans le menu de gauche.
  • Dans le cadre du haut, saisissez la période que l'état doit couvrir.
  • Cliquez sur Générer l'état.
  • L'état au format Excel se télécharge.
