Comment déclarer une absence ?

  • Cliquez sur le menu "Déclarer manuellement" si ce n'est pas déjà fait.
  • Saisissez la date du cours, sachant que la date du jour est automatiquement remplie.
  • Cochez le ou les créneaux horaires correspondants à l'absence que vous souhaitez déclarer.
  • Sélectionnez le cours concerné puis, si vous le souhaitez, le type du cours.
  • Cochez le ou les étudiants absents. La liste déroulante contenant les groupes n'est là que pour trier la liste des étudiants. Vous pouvez donc, en l'utilisant, saisir plusieurs groupes en une fois.
  • Cliquez sur "Déclarer l'absence" pour que votre saisie soit enregistrée.
  • Un message de confirmation vert vous indique le nombre d'absences enregistrées. Si ce message n'apparaît pas, c'est qu'il y a eu un problème (manque un champ, valeur incorrecte...)

Comment voir les absences que j'ai déclaré ?

  • Cliquez sur le menu "Gérer les absences".
  • Les étudiants que vous avez déclarés absents s'affichent.
  • Cliquez sur le pour voir les détails.
    • L'icône signifie que l'absence a été justifiée par un certificat médial.
    • L'icône signifie que l'absence a été justifiée par une convocation administrative.
    • L'icône signifie que l'absence a été justifiée par le responsable de formation.
    • L'icône signifie que l'absence a été justifiée par le responsable de formation.
    • L'absence de symbole signifie que cette absence n'est pas justifiée.
    • Le message en rouge, s'il est présent, indique le motif de l'absence.
  • Vous avez la possibilité de filtrer les absences par cours ou par groupe, en utilisant les liens situés au dessus des absences.
  • Vous pouvez également consulter si les étudiants ont été absents à d'autres cours qu'au vôtre, en cliquant sur "Cliquez ici pour voir les absences déclarées par les autres enseignants".

Comment supprimer une absence ?

  • Cliquez sur le menu "Gérer les absences".
  • Cliquez sur le à côté de l'étudiant dont vous souhaitez supprimer une absence.
  • Cliquez sur le bouton .
  • Un message de sécurité apparaît, puis, si vous cliquez sur Oui, un message de confirmation vers apparaît. S'il un message rouge apparaît, c'est qu'il y a eu une erreur.
  • Si le bouton n'apparaît pas, cela signifie que l'absence n'est plus supprimable. Contactez votre responsable de formation.
