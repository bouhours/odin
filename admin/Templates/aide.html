Comment démarrer ?

  • Créez les personnels de votre département.
  • Définissez vos périodes d'enseignements.
  • Saisissez les maquettes de vos formations.
  • Affectez les enseignants aux matières.
  • Préparez vos fiches de renseignement (facultatif)
  • Inscrivez vos étudiants.
  • Saisissez les informations manquantes des étudiants.
  • Créez vos groupes d'étudiants.
  • Affectez vos étudiants aux différents groupes.

Comment créer un enseignant ?

  • Cliquez sur le menu "Personnel"
  • Saisissez le nom de la personne que vous souhaitez ajouter.
  • En dessous du bouton, la liste des personnes ayant le même nom apparaît. Cherchez la véritable personne et cliquez sur "Choisir cette personne".
  • Si vous ne trouvez pas la bonne personne, c'est qu'elle n'existe pas encore dans la base de l'université. C'est souvent le cas pour les nouveaux vacataires.
  • Dans ce cas, vous pouvez le créer temporairement en cliquant sur le bouton "Pour ajouter un enseignant dont le dossier n'est pas encore prêt, indiquez son NOM et son Prénom dans le champ ci-dessus".
  • Vous pourrez modifier les informations lorsque l'enseignant sera créé, en cliquant sur puis sur situé à côté de son nom. Attention, un enseignant créé temporrairement ne pourra pas se connecter.

Comment définir une période d'enseignement ?

  • Cliquez sur le menu "Périodes"
  • Une période d'enseignement permet à Odin de gérer les relances pour les limites de saisie des notes, les emplois du temps et les retours des étudiants. Si vous n'êtes pas concernés par une ces trois fonctionnalités, vous n'avez besoin que d'une période (représentant l'année)
  • Créez une période en saisissant son nom et la ou les formations concernés (deux formations maximum par période).
  • En cliquant sur à côté d'une période, vous pouvez modifier les formations concernées tant qu'elles n'utilisent pas la période.
  • Pour ceux qui sont concernés par l'outil de création des emplois du temps assistée par Odin, les lignes suivantes vous concernent, sinon, vous pouvez tout laisser vide.
  • La date limite de saisie indique à quel moment les fiches de voeux ne sont plus modifiables par les enseignants.
  • La date de début de signal, indique à partir de quand Odin relance les enseignants qui n'ont pas encore saisis leurs voeux. Cette relance a lieu tous les lundis matin.
  • L'année inidque quelle année scolaire concernée par l'emploi du temps.
  • Les dates d'enseignement et d'examen sont uniquement informatives sur les fiches de voeux.
  • Le nombre de semaines de la période permet à Odin de calculer dans quel ordre il faut faire les emplois du temps.

Comment créer sa maquette ?

  • Cliquez sur le menu "Maquette" puis déroulez les formulaires de création en cliquant sur le en bas de la page
  • Vérifiez que vous travaillez sur la bonne année.
  • Vous devez créer en partant de l'élément le plus haut (formation) et descendre jusqu'aux matières en passant par les semestres, les UEs et les modules.
  • Vous pouvez créer la maquette d'un seul coup en utilisant un fichier de création automatique, téléchageable en cliquant sur le lien indiqué.
  • Sinon, vous pouvez créer manuellement les éléments en utilisant les formulaires de saisie.
  • Les modules contiennent des matières ou des sous-modules. Ils sont rattachés soit à des UEs soit à d'autres modules.
  • Les matières contiennent des notes. Elles sont rattachées soit à des modules soit à des UEs.
  • Lorsque les créations sont faites, elles apparaissent de manière hiérarchiques.
  • Ne saisissez le code APOGEE que sur les modules ou les matières que vous souhaitez exporter.

Comment affecter un enseignant à une matière ?

  • Cliquez sur le menu "Enseignements".
  • Choisissez l'année et le semestre sur lesquels vous souhaitez travailler.
  • Dans cette page, vous pouvez affecter sur des matières les enseignants de votre département.
  • Faites bien attention à l'année d'affectation.

Comment préparer une fiche de renseignents (facultatif) ?

  • Cliquez sur le menu "Fiches de renseignements".
  • Choisissez la formation sur laquelle vous souhaitez travailler.
  • Saisissez le label et le type du champ que vous souhaitez créer.
  • Cliquez sur "Créer le champ" pour enregistrer.
  • Recommencez pour chaque champ.
  • Vous pouvez rendre des champs obligatoires en cochant les cases à cocher situées à côté de chaque champ. Tant qu'ils ne sont pas remplis par les étudiants, un mail relancera les étudiants chaque semaine.

Comment inscrire un étudiant à un semestre ?

  • Cliquez sur le menu "Inscriptions".
  • L'inscription se fait automatiquement à la date que vous indiquerez au support d'Odin. Pour les étudiants arrivés après la date donnée, il faut effectuer une inscription manuelle.
  • L'inscription manuelle consiste à créer un étudiant et à l'inscrire automatiquement au semestre indiqué. Il suffit de remplir le formulaire en bas de page. Le numéro de l'étudiant temporaire est obligatoire. Vous pouvez mettre celui que vous voulez à partir du moment où il est unique. Il sera automatiquement modifié lors de l'inscription officielle de l'étudiant.
  • Durant l'année, vous pouvez inscrire les étudiants aux semestres suivants, simplement en copiant les numéros indiqués dans les listes de gauche.

Comment modifier les informations d'un étudiant ?

  • Cliquez sur le menu "Etudiants".
  • La liste des étudiants inscrits apparait. Vous pouvez modifier les informations d'un étudiant en cliquant sur son nom.

Comment créer des groupes d'étudiants ?

  • Cliquez sur le menu "Groupes".
  • L'idée de cette page est de pouvoir créer des groupes, de manière hiérarchique.
  • Le groupe le plus haut est la promotion, puis les groupes de TD, puis les groupes de TP. Il est important de construire une hiérarchie dans laquelle un étudiant ne sera inscrit qu'une seule fois.
  • Créez d'abord un groupe contenant la promotion.
  • Créez ensuite des groupes de TD ou des groupes de TP. Attention, seuls les groupes de TP contiennent les étudiants.
  • Le responsable du groupe est l'enseignant qui assure le suivi des étudiants du groupes (absences, notes...)
  • Les groupes contenant les étudiants doivent être affectés à un ou plusieurs semestres.
  • Le code ADE est le numéro utilisé par ADE pour identifier le groupe. Il est à récupérer directement sous ADE.

Comment affecter des étudiants à des groupes ?

  • Cliquez sur le menu "Affectations groupes".
  • L'affectation des étudiants se fait uniquement dans les groupes de TP. Les groupes de TD et de promotion se remplissent automatiquement.
  • Saisissez les numéros d'étudiants dans chaque groupe puis cliquez sur "Mettre à jour le groupe"
