Comment déclarer qu'on a emprunté un objet ?

  • Cliquez sur le menu "Emprunter" si ce n'est pas déjà fait.
  • Sélectionnez l'objet que vous souhaitez emprunter.
  • Indiquez le nombre d'objets que vous souhaitez emprunter.
  • Indiquez, si vous la connaissez, la date de rendu prévue.
  • Normalement, votre nom apparaît déjà en tant qu'emprunteur.
  • Cliquez sur "Enregistrer l'emprunt" pour que votre emprunt soit enregistré.
  • Un message de confirmation vert vous indique l'emprunt a été correctement enregistré.

Comment déclarer qu'on a prêté un objet à quelqu'un ?

  • Cliquez sur le menu "Emprunter" si ce n'est pas déjà fait.
  • Sélectionnez l'objet que vous souhaitez prêter.
  • Indiquez le nombre d'objets que vous souhaitez prêter.
  • Indiquez, si vous la connaissez, la date de rendu prévue.
  • Sélectionnez le nom de la personne a qui vous prêtez l'objet. S'il n'est pas dans la liste, saisissez sont nom dans le champ prévu juste en dessous.
  • Cliquez sur "Enregistrer l'emprunt" pour que votre emprunt soit enregistré.
  • Un message de confirmation vert vous indique l'emprunt a été correctement enregistré.

Comment déclarer qu'on a prêté un objet à un étudiant ?

  • Ce n'est pas à vous de déclarer l'emprunt, mais à l'étudiant. Précisez bien à l'étudiant concerné qu'il doit absolument faire la déclaration sur la plateforme.

Comment savoir qui détient un objet déjà emprunté ?

  • Cliquez sur le menu "Rendre".
  • La liste des objets empruntés apparaît avec toutes les informations nécessaires.

Comment rendre un objet emprunté ?

  • Cliquez sur le menu "Rendre".
  • La liste des objets empruntés apparaît, avec le vôtre.
  • Cliquez sur le bouton Rendre.
  • Un message de confirmation vert vous indique que le rendu a bien eu lieu.
  • Attention, le rendu s'effectue un par un.

Comment rendre un objet emprunté pour quelqu'un ?

  • Seul l'emprunteur ou le prêteur peut rendre l'objet. Si vous êtes dans ce cas là, la procédure est la même que pour rendre un objet emprunté (voir ci-dessus).

Comment ajouter un objet à la liste des objets empruntables ?

  • Cliquez sur le menu "Ajouter un objet".
  • Saisissez le nom de l'objet.
  • Saisissez le nombre d'objets en stock.
  • Saisissez le lieu de stockage.
  • Cliquez sur le bouton Ajouter un nouvel objet.
  • Un message de confirmation vert vous indique que le nouvel objet a bien été créé.

Comment modifier un objet de la liste des objets empruntables ?

  • Cliquez sur le menu "Ajouter un objet".
  • Repérez dans la liste l'objet concerné.
  • Modifiez directement dans les champs les informations désirées.
  • Le champ passe au vert dès que votre curseur sort du champ. Cela indique que la modification est enregistrée. Si le champ passe au rouge, c'est que l'enregistrement n'a pas eu lieu. Dans ce cas, contactez le responsable de formation (cedric.bouhours@uca.fr).
